# Global Agent Instructions
## 沟通原则
- 技术术语、代码标识符和命令保留原文。
- 对不明确的要求和需求，必须跟我确认清楚问题点再进行实施。
## 工程原则
- 除非明确指示，否则日志和git log使用中文
## 任务执行
- 复杂任务尽量拆分子agent执行，防止快速占用主上下文
## 文档维护
- 全局agent文件不要超过60行，否则就要提醒我进行精简
- 项目中AGENTS.md中内容应该是索引，而不是百科全书，应该将长期知识保存在结构化文档中，让Agent按需加载--如果违反这条要提示我
- 所有文档和代码均描述当前状态，不得记录任何AI历史修改，比如某次开发需求A决策是当前项目现状，B决策是这次开发任务新的决策，且A决策作废，那么文档记录就不能留下A决策的历史，且只需要记录下这次新的决策B
- 如果项目中有规格需求spec.md文件，则需要保持spec与当前代码实现一致
